# Fox-Li LASER Cavity Simulator

## Version 1

### Engine: NumPy

A graphical desktop application for the numerical simulation and analysis of optical laser resonators using the Fox-Li iterative method.

---

# Features

- Fox-Li cavity simulation
- Circular mirror aperture
- Mirror misalignment modelling
- External gain profile loading
- Near-field intensity visualization
- Near-field phase visualization
- Far-field beam analysis
- M² beam quality calculation
- Export simulation figures
- Export simulation report (.txt)

---

# Numerical Backend

- NumPy
- SciPy
- Pandas
- Matplotlib
- PyQt5

CPU execution only.

---

# Requirements

Python 3.12+

Dependencies

- numpy
- scipy
- pandas
- matplotlib
- PyQt5
